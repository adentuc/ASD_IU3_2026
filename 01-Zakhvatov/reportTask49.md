# Задача 49. Сумма строк матрицы

## Идея решения
Создаем массив `res` длины `n`. Внешним циклом проходим по строкам матрицы, во внутреннем цикле суммируем элементы текущей строки и записываем сумму в `res[i]`.

## Асимптотика
- Время: O(n * m) — проходим по каждой ячейке матрицы один раз.
- Память: O(n) — массив для хранения сумм n строк.

## Примеры тестов
- `[[1, 2, 3], [4, 5, 6]]` -> `[6, 15]` — прямоугольная матрица 2x3.
- `[[1, 2], [3, 4], [5, 6]]` -> `[3, 7, 11]` — матрица 3x2.
- `[[-1, 1], [-5, 5]]` -> `[0, 0]` — отрицательные числа, дающие в сумме 0.
