# Задача 37. Разворот массива

## Идея решения
Разворачиваем массив на месте с помощью двух указателей: один ставим на начало (`l = 0`), второй на конец (`r = n - 1`). Пока `l < r`, меняем элементы местами через переменную `tmp` и сдвигаем указатели навстречу друг другу.

## Асимптотика
- Время: O(n) — цикл делает n/2 итераций.
- Память: O(1) — разворот in-place, новый массив не создается.

## Примеры тестов
- `[1, 2, 3, 4, 5]` -> `[5, 4, 3, 2, 1]` — нечетная длина, центральный элемент остается на месте.
- `[10, 20, 30, 40]` -> `[40, 30, 20, 10]` — четная длина.
- `[7, 7, 7]` -> `[7, 7, 7]` — одинаковые элементы.
- `[1, 2]` -> `[2, 1]` — минимальный размер массива (2 элемента).
