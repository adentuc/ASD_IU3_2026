# Задача 2. Индекс первого вхождения

## Идея решения
Проходим по массиву слева направо. Как только встречаем элемент, равный `x`, сразу возвращаем его индекс `i`. Если цикл закончился и совпадений не было, возвращаем `-1`.

## Асимптотика
- Время:
  - Лучший случай: O(1), если нужный элемент стоит на первом месте (индекс 0).
  - Худший случай: O(n), если элемент стоит в самом конце или отсутствует.
- Память: O(1) — используется только индекс цикла.

## Примеры тестов
- `arr = [10, 20, 30, 20, 50], x = 20` -> `1` — в массиве несколько одинаковых чисел, возвращается первое.
- `arr = [5, 1, 3], x = 10` -> `-1` — числа нет в массиве.
- `arr = [42, 7, 9], x = 42` -> `0` — элемент на первой позиции.
- `arr = [-5, 8], x = 8` -> `1` — массив из двух элементов.
