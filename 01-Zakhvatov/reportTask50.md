# Задача 50. Сумма столбцов матрицы

## Идея решения
Создаем массив `res` длины `m`. Внешним циклом идем по столбцам `j` от 0 до `m - 1`, внутренним циклом суммируем элементы по строкам `i` от 0 до `n - 1`. Полученную сумму сохраняем в `res[j]`.

## Асимптотика
- Время: O(n * m) — каждый элемент матрицы просматривается ровно один раз.
- Память: O(m) — массив для сумм m столбцов.

## Примеры тестов
- `[[1, 2, 3], [4, 5, 6]]` -> `[5, 7, 9]` — прямоугольная матрица (больше столбцов).
- `[[1, 2], [3, 4], [5, 6]]` -> `[9, 12]` — прямоугольная матрица (больше строк).
- `[[-2, 3], [2, -3]]` -> `[0, 0]` — отрицательные числа.
