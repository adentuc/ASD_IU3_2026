# Задача 40. Удаление дубликатов из отсортированного массива

## Идея решения
Так как массив уже отсортирован, одинаковые элементы стоят рядом.
Используем два указателя:
- `k = 1` указывает, куда записывать следующий уникальный элемент;
- `i` идет от 1 до `n - 1`.
Если `arr[i] != arr[k - 1]`, записываем `arr[k] = arr[i]` и сдвигаем `k++`. Первые `k` элементов исходного массива становятся уникальными. Затем создаем массив длины `k` и копируем туда ответ.

## Асимптотика
- Время: O(n) — один проход по массиву и копирование k элементов в результат.
- Память:
  - Алгоритм сжимает массив на месте за O(1) памяти.
  - O(k) дополнительной памяти уходит на результирующий массив длины k.

## Примеры тестов
- `[1, 1, 2, 2, 3, 4, 4]` -> `[1, 2, 3, 4]` — обычный массив с дубликатами.
- `[1, 2, 3, 4]` -> `[1, 2, 3, 4]` — дубликатов нет.
- `[5, 5, 5, 5]` -> `[5]` — все элементы одинаковые.
- `[-3, -3, -1, 0, 0, 2]` -> `[-3, -1, 0, 2]` — отрицательные числа и ноль.
