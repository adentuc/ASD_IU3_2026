# Задача 4. Все индексы элемента

## Идея решения
Делаем решение в два прохода:
1. Сначала считаем, сколько раз число `x` встречается в массиве.
2. Создаем массив `res` нужного размера и вторым проходом записываем в него индексы совпадений. Так как идем слева направо, индексы сразу получаются отсортированными по возрастанию.

## Асимптотика
- Время: O(n) — два последовательных прохода по массиву длины n, суммарно 2n операций.
- Память: O(k), где k — количество найденных вхождений (в худшем случае n).

## Примеры тестов
- `arr = [10, 20, 10, 30, 10], x = 10` -> `[0, 2, 4]` — несколько вхождений, индексы идут по возрастанию.
- `arr = [1, 2, 3], x = 9` -> `[]` — число не найдено, возвращается пустой массив.
- `arr = [5, 5, 5], x = 5` -> `[0, 1, 2]` — все элементы совпадают с x.
- `arr = [-1, 2], x = -1` -> `[0]` — массив из двух элементов, отрицательное число.
