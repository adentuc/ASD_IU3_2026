# Задача 38. Циклический сдвиг влево

## Идея решения
Используем метод трех разворотов:
1. Берем `k = k % n`. Если `k < 0`, делаем `k += n`.
2. Разворачиваем первые `k` элементов: от 0 до `k - 1`.
3. Разворачиваем оставшуюся часть: от `k` до `n - 1`.
4. Разворачиваем весь массив целиком: от 0 до `n - 1`.
В итоге получается циклический сдвиг влево на `k` позиций без создания второго массива.

## Асимптотика
- Время: O(n) — три последовательных разворота суммарно обрабатывают k + (n - k) + n = 2n элементов.
- Память: O(1) — сдвиг делается на месте.

## Примеры тестов
- `arr = [1, 2, 3, 4, 5], k = 2` -> `[3, 4, 5, 1, 2]` — стандартный сдвиг влево.
- `arr = [1, 2, 3], k = 0` -> `[1, 2, 3]` — сдвиг на 0 позиций.
- `arr = [1, 2, 3, 4], k = 6` -> `[3, 4, 1, 2]` — сдвиг на число больше длины массива (6 mod 4 = 2).
- `arr = [10, 20], k = 1` -> `[20, 10]` — массив из двух элементов.
