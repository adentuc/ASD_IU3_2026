# Задача 51. Максимум в каждой строке матрицы

## Идея решения
Создаем массив `res` длины `n`. Для каждой строки берем первый элемент как начальный максимум `max = matrix[i][0]`, проходим по остальным элементам строки и при нахождении большего обновляем `max`. Записываем максимум строки в `res[i]`.

## Асимптотика
- Время: O(n * m) — обходим все элементы матрицы.
- Память: O(n) — массив результатов для n строк.

## Примеры тестов
- `[[1, 5, 3], [8, 2, 4]]` -> `[5, 8]` — обычная матрица.
- `[[-10, -5, -20], [-1, -8, -3]]` -> `[-5, -1]` — отрицательные числа в строках.
- `[[7, 7], [3, 3]]` -> `[7, 3]` — строки из одинаковых элементов.
