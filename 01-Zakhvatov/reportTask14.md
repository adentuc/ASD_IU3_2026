# Задача 14. Сортировка вставками

## Идея решения
Реализована сортировка вставками по невозрастанию (убыванию). Начиная со второго элемента (`i = 1`), сдвигаем текущий элемент влево в уже отсортированную часть, пока левый сосед меньше текущего (`arr[j-1] < arr[j]`).

## Асимптотика
- Время:
  - Худший случай: O(n^2), если массив был отсортирован по возрастанию (каждый элемент приходится сдвигать до самого начала).
  - Лучший случай: O(n), если массив уже отсортирован по убыванию — внутренний цикл сразу завершается на первой проверке.
- Память: O(1) — сортировка выполняется на месте.

## Примеры тестов
- `[12, 11, 13, 5, 6]` -> `[13, 12, 11, 6, 5]` — обычный случай.
- `[5, 4, 3, 2, 1]` -> `[5, 4, 3, 2, 1]` — лучший случай, массив уже отсортирован по убыванию.
- `[1, 2, 3, 4, 5]` -> `[5, 4, 3, 2, 1]` — худший случай, массив в обратном порядке.
- `[4, 2, 4, 1, 2]` -> `[4, 4, 2, 2, 1]` — дубликаты в массиве.
- `[-10, 0, 15, -20]` -> `[15, 0, -10, -20]` — отрицательные числа и ноль.
