# Задача 26. Произведение элементов по модулю 10^9 + 7

## Идея решения
Перемножаем элементы массива по очереди в переменной `long p = 1`. После каждого умножения берем остаток по модулю `1000000007L`. Если получилось отрицательное число (так как в Java остаток от отрицательного делимого отрицательный), прибавляем модуль: `p += mod`.

## Асимптотика
- Время: O(n) — один проход по массиву.
- Память: O(1) — переменная для произведения.

## Примеры тестов
- `[2, 3, 4]` -> `24` — небольшие числа без выхода за модуль.
- `[1000000, 2000000]` -> `999999986` — проверка взятия по модулю при превышении 10^9+7.
- `[-2, 3]` -> `1000000001` — отрицательное произведение (-6 mod 10^9+7 = 10^9+1).
- `[5, 0, 10]` -> `0` — массив с нулем дает 0.
