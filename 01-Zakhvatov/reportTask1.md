# Задача 1. Максимум и минимум

## Идея решения
Проходим по массиву за один цикл и находим минимальный и максимальный элементы, обновляя переменные `min` и `max`. Входные данные хранятся в обычном `int[]`, результат возвращается массивом из двух чисел `[min, max]`.

## Асимптотика
- Время: O(n) — массив просматривается один раз.
- Память: O(1) — дополнительная память нужна только для двух переменных и массива ответа из 2 элементов.

## Примеры тестов
- `[3, 1, 9, 2, 5]` -> `[1, 9]` — обычный массив с положительными числами.
- `[-10, -5, -20, 0, 7]` -> `[-20, 7]` — отрицательные числа и ноль.
- `[4, 4, 4, 4]` -> `[4, 4]` — все элементы одинаковые (минимум равен максимуму).
- `[100, -50]` -> `[-50, 100]` — минимальный размер массива (2 элемента).
