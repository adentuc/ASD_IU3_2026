# Задача 3. Подсчёт вхождений

## Идея решения
Заводим переменную-счетчик `k = 0`. В цикле обходим массив от начала до конца и при каждом равенстве `arr[i] == x` увеличиваем счетчик на 1. В конце возвращаем `k`.

## Асимптотика
- Время: O(n) — всегда проверяются все n элементов массива.
- Память: O(1) — только счетчик `k`.

## Примеры тестов
- `arr = [1, 2, 3, 2, 2, 4], x = 2` -> `3` — число встречается несколько раз в разных местах.
- `arr = [1, 2, 3], x = 5` -> `0` — числа нет в массиве.
- `arr = [7, 7, 7, 7], x = 7` -> `4` — все элементы массива равны искомому.
- `arr = [-3, -3], x = -3` -> `2` — отрицательные числа, массив из двух элементов.
