# Задача 16. Сортировка по модулю

## Идея решения
Используем сортировку вставками со специальным условием сравнения:
- сравниваем модули чисел `Math.abs((long) x)`. Приводим к `long`, чтобы не словить переполнение на `Integer.MIN_VALUE`.
- если модули равны, то отрицательное число должно идти перед положительным (например, `-5` раньше `5`).

## Асимптотика
- Время: O(n^2) в худшем случае, O(n) в лучшем случае (если массив уже упорядочен).
- Память: O(1) — сортировка на месте в исходном массиве.

## Примеры тестов
- `[5, -2, 3, -5, 1]` -> `[1, -2, 3, -5, 5]` — проверка равных модулей (|-5| = |5|, вперед встает -5).
- `[-3, 3, -3, 3]` -> `[-3, -3, 3, 3]` — все числа с одинаковым модулем.
- `[0, -1, 1]` -> `[0, -1, 1]` — ноль с наименьшим модулем.
- `[-5, -4, -3, -2, -1]` -> `[-1, -2, -3, -4, -5]` — только отрицательные числа.
