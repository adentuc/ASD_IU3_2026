# Задача 28. Медиана массива

## Идея решения
1. Клонируем массив `arr.clone()`, чтобы не менять исходные данные.
2. Сортируем копию вставками.
3. Если длина нечетная, возвращаем средний элемент `a[n / 2]`. Если четная — среднее двух центральных `(a[n / 2 - 1] + a[n / 2]) / 2.0`.

## Асимптотика
- Время: O(n^2) из-за сортировки вставками (в лучшем случае O(n)).
- Память: O(n) — для копии массива.

## Примеры тестов
- `[5, 2, 9, 1, 7]` -> `5.0` — нечетная длина, после сортировки [1, 2, 5, 7, 9], элемент посередине 5.
- `[4, 1, 7, 2]` -> `3.0` — четная длина, после сортировки [1, 2, 4, 7], среднее (2+4)/2 = 3.
- `[1, 2]` -> `1.5` — массив из 2 элементов, дробный ответ.
- `[-10, 0, 10]` -> `0.0` — отрицательные числа.
