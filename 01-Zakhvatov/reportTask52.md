# Задача 52. Минимум в каждом столбце матрицы

## Идея решения
Создаем массив `res` длины `m`. Для каждого столбца берем верхний элемент как начальный минимум `min = matrix[0][j]`, проходим вниз по строкам и обновляем `min`, если встретили элемент меньше. Записываем минимум столбца в `res[j]`.

## Асимптотика
- Время: O(n * m) — обход всех элементов матрицы.
- Память: O(m) — массив результатов для m столбцов.

## Примеры тестов
- `[[3, 8, 2], [5, 1, 7]]` -> `[3, 1, 2]` — прямоугольная матрица.
- `[[-5, -2], [-10, 0], [-1, -8]]` -> `[-10, -8]` — отрицательные числа в столбцах.
- `[[4, 4], [4, 4]]` -> `[4, 4]` — матрица из одинаковых чисел.
