# Задача 25. Сумма элементов

## Идея решения
Проходим по массиву и складываем все элементы. Чтобы сумма не переполнила 32-битный `int` при больших числах (до 10^5 элементов порядка 10^9), накапливаем результат в переменную типа `long`.

## Асимптотика
- Время: O(n) — один проход по массиву.
- Память: O(1) — одна переменная `long s`.

## Примеры тестов
- `[1, 2, 3, 4, 5]` -> `15` — обычный массив.
- `[-5, -10, 15, 0]` -> `0` — отрицательные числа и ноль, сумма дает 0.
- `[1000000000, 1500000000]` -> `2500000000` — проверка переполнения int (сумма больше 2*10^9).
- `[-100, 200]` -> `100` — массив из двух элементов.
