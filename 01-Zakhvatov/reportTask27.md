# Задача 27. Сумма квадратов

## Идея решения
Проходим по массиву и прибавляем к сумме квадрат каждого числа. Умножение делаем в типе `long`: `(long) arr[i] * arr[i]`, чтобы при возведении больших чисел в квадрат не произошло переполнения `int`.

## Асимптотика
- Время: O(n) — один проход по всем элементам.
- Память: O(1) — одна переменная `long s`.

## Примеры тестов
- `[1, 2, 3]` -> `14` (1 + 4 + 9).
- `[-2, -3]` -> `13` — отрицательные числа в квадрате дают положительный результат.
- `[100000, 100000]` -> `20000000000` — проверка переполнения int при умножении.
- `[0, 0]` -> `0` — нули.
